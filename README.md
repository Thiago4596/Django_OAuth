# Django_OAuth

Este repositório contém um exemplo simples de autenticação OAuth usando Django.

## Descrição

O projeto demonstra como integrar autenticação OAuth em uma aplicação Django, facilitando o login com provedores externos como Google, GitHub, entre outros.

## Funcionalidades

- Autenticação de usuários via OAuth
- Integração fácil com provedores de terceiros
- Exemplo básico para aprendizado ou extensão

## Como usar

1. Clone o repositório:
   ```bash
   git clone https://github.com/Thiago4596/Django_OAuth.git
   ```
2. Instale as dependências:
   ```bash
   pip install -r requirements.txt
   ```
3. Configure as credenciais OAuth nas variáveis de ambiente.
4. Execute as migrações e inicie o servidor:
   ```bash
   python manage.py migrate
   python manage.py runserver
   ```
